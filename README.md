# Under Divided Stars: playtest feedback page

The page friends use to send feedback on the Under Divided Stars playtest (Windows build of 28 October 2026).
It holds only the page and its pictures; the game and its source are not here.

Answers go to the creator's private Google Sheet. The page keeps nothing except, on the tester's own device,
their guest number and any unsent answers.
